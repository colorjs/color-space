# Color Spaces

![Picking a color in a stylesheet](https://raw.githubusercontent.com/colorjs/color-space/master/plugins/vscode/media/picker.gif)

Edit the colors in your code in OKLCH, Display P3 or any of 205 color spaces.

Open **Color Space** in the secondary side bar, put the cursor on a color, drag.

- Reads CSS, Swift, Flutter, Jetpack Compose, Unity, Godot, Unreal, design tokens, themes and palettes.
- Writes each edit back in the color's own notation.
- Shows all the file's colors on one plane: gradients as lines, image pixels as dots.
- Edits a CSS, Sass or Less variable from any of its uses in the file.
- Hover a color for its OKLCH, Display P3 and hex.

Settings: `colorSpace.gamut` (`p3` or `srgb`), `colorSpace.shaders` (read shader vectors as colors).
