**Official MCP registry**: io.github.colorjs/color-space


**Name:** color-space

**Description**: Color conversions math for 200+ color spaces, including OKLCH, CIELAB, CAM16, HCT, Display P3, Rec. 2020, camera logs, print and appearance models. Every space is verified against an authoritative reference. A color goes in as any CSS string or as channel values. Tools: convert, gamut, css, space, spaces, cube, shader, icc and code. No API key, no configuration and no network.
